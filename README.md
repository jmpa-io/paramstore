# `devex-template`

```diff
+ A template for DevEx to use to help create new projects and manage existing ones.
```

## `usage`

1. Using a <kbd>terminal</kbd>, download a repository you want to add this template to.

2. From the root of this downloaded repository, using a <kbd>terminal</kbd>, run:

```bash
git remote add template https://github.com/myob-ops/devex-template.git
git fetch template
git merge template/main --allow-unrelated-histories
```

3. Fix any merge conflicts; push the changes up.

4. The repository is now integrated! :1st_place_medal:
